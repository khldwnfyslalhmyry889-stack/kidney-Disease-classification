📑 تقرير بحثي: تصنيف أمراض الكلى باستخدام تقنيات التعلم العميق
1. المقدمة والأهداف
يتمحور هذا المشروع حول تطوير نظام برمجيات ذكي متكامل (MLOps) يهدف إلى تصنيف صور الأشعة المقطعية للكلى بشكل آلي. يسعى النظام إلى تقديم تحليل أولي يدعم الكوادر التقنية والطبية، من خلال فرز الصور بدقة إلى أربع فئات تشخيصية هي: الكيسات (Cyst)، الأورام (Tumor)، الحصوات (Stone)، والحالات السليمة (Normal).
2. البنية البرمجية والمنهجية (MLOps)
تم تصميم المشروع وفقاً لأفضل الممارسات الهندسة البرمجية للذكاء الاصطناعي، لضمان استدامة النظام وقابليته للتطوير:
• البيئة التقنية: اعتمد التطوير على لغة Python 3.8 وإطار عمل TensorFlow 2.10.1 لضمان استقرار حزم البرمجيات.
• إدارة المدخلات والتجارب: تم فصل الإعدادات البرمجية داخل ملفات مستقرة (config.yaml) لربط مسارات البيانات وعمليات التدريب والتنبؤ بشكل منظم ونمطي (Modular Architecture).
• واجهة التشغيل: تم بناء نظام ويب تفاعلي باستخدام Flask، يتيح للمستخدم رفع الصور الطبية بشكل آمن، واستدعاء مصفوفة الأوزان المدربة لاستخراج النتائج فورياً عبر الرابط المحلي http://127.0.0.1:5000.
3. تحليل نتائج الأداء والتقييم
خضع النموذج للاختبار والتقييم على مرحلتين أساسيتين:
• المرحلة الأولى (النموذج الأساسي): حقق كفاءة تصنيفية إجمالية (Validation Accuracy) بلغت 90.72%، ومعدل توازن للمقاييس (Macro F1-Score) بنسبة 89.26%.
• المرحلة الثانية (الضبط الدقيق Fine-tuning): أظهرت التجارب تحسناً ملحوظاً في تقليص دالة الخسارة لتصل إلى (0.00019)، مما يثبت قدرة النموذج على التكيف العالي مع البيانات الطبية المتاحة بعد ضبط الأوزان.
مؤشرات الأداء التفصيلية لكل حالة مرضية:
• Cyst: سجلت دقة تصنيف عالية بلغت 91.95% وقدرة استدعاء (Recall) بلغت 97.56%.
• Normal: أظهر النموذج دقة استثنائية في التعرف على الحالات السليمة بلغت 94.32%.
• Tumor: تميز النظام بقدرة تصنيفية متزنة للأورام بلغت 92.50%.
• Stone: سجلت فئة الحصوات أقل معدل دقة (75.21%)، وهو مؤشر علمي يوصي بزيادة عينات هذه الفئة مستقبلاً لتفادي التداخل في الأنماط البصرية.
4. جودة البرمجيات والامتياز
اجتاز النظام اختبارات الجودة والصيانة البرمجية المحلية بنجاح، حيث شملت:
• تدقيق الصياغة لـ 41 ملفاً برمجياً.
• عزل وحماية البيانات والأوزان الثقيلة عن مستودعات Git البرمجية لضمان أمن المعلومات وحفظ مساحات التخزين.
